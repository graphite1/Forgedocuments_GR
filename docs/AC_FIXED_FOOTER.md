# AC住所の固定テンプレート化（1.3.4候補）

住所「愛知県豊明市栄町神田182」は、社名の直上の1行・均等字間で印字する。伝票の入力項目には追加せず、通常設定画面では値を編集するEntryを持たない。固定文字のJSONも標準プロファイルのガードで位置・大きさ・字間・文言を保持し、ランダム印字は入力値だけへ作用させる。

## 根拠と未完の照合

対象はR_SCAN0238.pdf（Library libfile_2212a3b6aaa481919817fbfd71265d13、全2ページ・3伝票）。ユーザー側の原本画像レビューでは、住所は社名の直上、広い均等字間で、両端がほぼ一致する。1000×1300座標系で住所の見える範囲は概算x210～790/y1108～1132、社名はx210～795/y1144～1185と提供された。

この実行環境では現行の正規Library取得準備に成功したが、通常Pythonと保存済み環境のPythonによる2回のバイト転送がdownload failedで失敗した。読めるローカル原本PDFはなく、PDFの全2ページ・3伝票の実画像確認と実出力の重ね合わせを完了していない。したがって今回の座標は提供レビューを基にした候補であり、完全な位置一致を主張しない。

旧社名[62,1100,900,60]/font40、旧住所[62,1165,900,46]/font28は上下が逆で左寄りだった。候補の住所レイアウト枠は[210,1104,580,34]/font24、社名は[210,1138,585,60]/font44。これは文字の余白を含むレイアウト枠であり、原本のインクの外接範囲とは異なる。CID代替フォントで出力・視認し、住所が上に1行で、社名と横端が揃うことを確認した。原票PDFとWindowsの字体を実ピクセルで比較してから最終調整する必要がある。

## 移行と保護

`ac_footer.py` は旧標準の住所文字列・枠・サイズが一致するものだけを移行する。住所をvalue_key参照からliteralの固定要素へ変え、旧配置定義を`ac_previous_footer`とSQLite設定履歴へ残す。社名の旧標準枠も同時に移動する。文言は会社専用モジュールへ置き、共通PDF描画は汎用の均等字間だけを担当する。

独自住所・寸法・非表示・旧住所フィールド・矛盾する旧設定は勝手に再分類・上書きしない。既存記録・訂正履歴を書き換えない。移行の再実行で設定履歴を増やさない。

## 検証

住所の固定文字・1行の共通baseline・均等字間、社名直上の位置、ランダム印字ON/OFFで住所部分の実画素差0と罫線不変を検証する。GUIに編集可能な住所Entryがないこと、JSONからの固定位置変更を拒否すること、旧標準の一度だけの移行と記録・訂正履歴保持、独自帳票と独自設定の不変も確認する。見本PDF/PNGはprivate/fixed-footer-and-preset/に置き、公開Gitへ入れない。
