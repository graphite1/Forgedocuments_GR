## 画像用座標と導入

新画像は説明図のセル形状・縦横比と異なる。旧118.3×176.5mm座標は保持し、`generated-20261014` を明示的に選ぶ独立プロファイルを追加した。切り出しは元画像の `[26,33,1044,1450]`、1018×1417 pixels。画像内の組合名も含む。幅118.3mmを暫定尺度にして背景高164.67mm、計画表示を含む高さ171.64mmとし、縦横同倍率で配置する。原票実寸の確定ではない。

37黒入力を実セルに配置し、年月日・発時分を分割する。比率欄は青い見出しと％の間だけを値領域とし、5選択肢のチェック位置も修正画像へ合わせた。入力可能な配合計画番号と組合名は備考下部に置く。画像最下部の青い組合名は固定背景として残す。各伝票の「納入書（計画）」は濃い27px相当（暫定尺度で約3.14mm）とし、四面付けでも読める大きさにする。着時刻の「着」「時」「分」と署名見出しは保持し、値領域を白くする。

修正背景と既存設定を使う例。出力先が存在する場合は上書きしない。`--reviewed` は画像の誤字・空欄・細字・罫線を確認した場合だけ指定する。未指定なら候補を保存し出力を停止する。

```text
python -B tools/prepare_tomei_plan.py CORRECTED_BACKGROUND.png --existing EXISTING_SETTINGS.json --reviewed --output PRIVATE_NEW_SETTINGS.json
```

新規設定なら `--existing` を省略する。「帳票設定」→「設定JSONを取込」→内容を確認→「設定を適用・保存」で取り込む。アプリの既存設定履歴に旧設定が残り、記録・訂正履歴は変更しない。独自座標を自動置換しない。画像プロファイルの明示取込時だけ座標を差し替える。背景はbase64とハッシュで設定JSON・SQLite設定履歴・バックアップへ含まれる。

汎用の原票青画素抽出は `tools/prepare_blue_background.py`、mm座標のコンパイルは `input_coordinates.py`、背景検証・空欄マスクは `background_assets.py`、画像合成は `background_compositor.py`、用紙配置は `page_layout.py` が担当する。会社情報は共通機構へ直書きしない。Windowsビルドは追加座標JSONも同梱するが、私有背景は同梱しない。
