# 東名太平洋生コン・転記再出力（仕様に基づく候補）

この帳票は実際の納入記録を利用者が入力・転記して再出力するものです。数量・配合・日時を乱数で創作しません。欄外下部「再生成」の識別表示を付け、認証マーク画像・署名画像・背景スキャンを使用しません。

識別表示を消す・白色にする・読めない大きさへ縮める・別の値に置き換える設定は拒否します。原票に近づける罫線・余白・字体の調整にも、この表示と着時刻・署名の空欄保持を適用します。

了承された表示方式は各伝票の外枠下部「再生成」です。枠から177mmの行の右側へ灰色2.2mmで表示し、左側の組合名の印字範囲を90mmへ収めています。原本相対の組合名座標は保存します。面付けでも伝票ごとに表示されます。追加提供されたJIS素材は正規転送に失敗しており未反映です。

## 定義と画面

- 安定ID: `tomei_taiheiyo`。
- `templates/tomei_taiheiyo.json`: 提供された42項目、罫線、固定文字、原本相対mm座標、推定を含む印字範囲。
- `tomei_screen.py`: 生コン固有の入力・色・禁止欄・識別表示の検証。
- `definition_screen.py`: 定義から作る共通の単票入力、保存、CSV一括取込、選択/全件出力、設定画面。

アプリ候補の帳票選択画面から開けます。ACと別の保存先を使います。ACの設定・住所・計算を流用しません。誤った旧AC保存先を選んだ場合は、設定移行や記録変更の前に拒否します。

## 青固定・黒入力

42項目のうち、発行元と原票記載認証文字列は青い固定設定、着時刻と署名2欄は空欄保持、残る37項目は黒い入力です。黒字の原票実績を初期値としてコピーせず、すべて空欄から開始します。必要な候補・既定値・固定値は利用者が確認した表記を設定できます。配合の組合せを自動補完しません。

固定表題: 「レディーミクストコンクリート納入書」。表題は明朝風の近似で、Windowsの既存MS明朝があれば使用し、正確な原票フォント名との一致は主張しません。

固定発行元:

```text
東名太平洋生コン株式会社
〒470-0162
愛知県愛知郡東郷町大字春木字南切山127番地
TEL （0562）92－5171
```

工場名・FAXは追加しません。原票記載認証文字列はユーザー指定の `GB0407016` を維持します。提供された照合情報では公式ページの `BG0407016` と異なります。これは原票記載文字列の保持であり、認証の正当性を検証済みという表示ではありません。

「西三河生コンクリート協同組合」を含む欄外組合名は黒い入力欄です。サンプル表記を初期値に残しません。

## 永続的な空欄保持

`arrival_time`、`recipient_sign_status`、`shipping_staff_status` は入力ウィジェットを作りません。CSVにも含めず、これらの列や値を取り込もうとすると拒否します。保存・設定検証でも非空値、入力可否や型の変更、有効化を拒否します。

描画は `layout_only` を値の有無に関係なくスキップします。原票の青い見出し・単位・枠は保持します。別の入力項目・固定文・追加の線を禁止欄へ配置する設定も拒否します。背景スキャンから手書きが混入する経路はありません。

## 用紙と入力表記

標準はA5縦148×210mm。外枠左上は用紙からX14.4/Y13.3mm、外枠は118.3×176.5mm。欄外組合名の5mmを含め、面付けの出力領域は高さ181.5mmです。

行数×列数、用紙・向き、余白、間隔、原寸/縮小、左/中央・上/中央配置は共通機構を使います。A4の2行×2列には縮小が必要です。端数枠は空白で、組合名が次の枠に重ならないよう出力領域も縮小・配置します。

日付はYYYY-MM-DD、発時刻はHH:MM、数値は文字列のまま保存します。`005.500`や車両番号`0012`を勝手に整形しません。配合計画書NO.欄には、印字したい行の内容をそのまま入力します。未知の接頭辞・番号・実績は補完しません。

配合種別は提供された5つの文を青い選択肢と未選択枠で表示し、選択状態を黒で表示します。初期はすべて未選択。CSVの「配合の種別」列は選択キーのJSON配列を使います。キーは定義の`options`にあり、画面では原票の日本語文で選べます。未知のキー・重複した選択は拒否します。

本仕様には納入伝票番号の独立項目がありません。番号を捏造したり配合計画書NO.を伝票番号へ自動転用したりしません。指定チェックシートの見本・照合キーを受領するまでは、同じ記録集合の件数・納入容積m³合計だけを集計します。

## 確認と推定

親から提供された42項目・色分類・枠と表題の解析仕様を実装しています。このクラウドで元PDFの実ピクセルを直接比較できたわけではありません。原本相対`source_bbox_mm`を保持し、見出し/値の境界から印字領域を分けています。備考と配合計画書行は重ならないように領域を分離しています。字形、色の数値、細分罫線、入力文字のベースライン、選択記号は原票との最終照合が必要です。

生成した確認用PDFは架空の試験入力を明示したもので、実際の納入記録ではありません。クラウド検証では既存の日本語CID代替フォントを使用し、Windowsの印字字体・EXE・実印刷は未確認です。
