# AKTIO 計量・運搬計画

帳票選択から開く独立モジュールです。AC・東名の記録や設定を共有しません。
保存先はアプリの `data/aktio_receipt`。入力、訂正理由と変更前後、生成条件、計画、用紙と出力見本文字色の選択をSQLiteへ自動保存します。JSONへの退避・読込もできます。既存データの読込前とExcelの入替前にはバックアップを残します。破損・別帳票・実測と計画の混在は上書きせず停止します。別画面からの同時更新も検出します。

「計量入力」はExcelまたは手入力による転記です。原本Excelを上書きしません。TOTALは6つの軸左右重量と照合し、未入力を乱数で補いません。手入力・訂正には理由を記録します。空車の初期設定は11180kgです。

「運搬予定」は重量を10kg刻みで生成する計画です。実計量記録ではありません。各車は空車1回＋指定した運搬回数、または空車・積載・積載の時刻とSNを指定した3枚を作成します。指定時刻とSNを保持し、休憩、稼働時間、同車の間隔、計量器の間隔、SN重複、積載・総重量の上限を確認します。seed=0も固定seedとして再現できます。条件を変更した計画は再生成が必要です。

計画由来の単票・全件PDF/PNG・プレビュー・印刷には、伝票枠外の下側に読める「出力見本」を必ず表示します。枠・罫線・塗りつぶしを追加せず、本文や数値位置は変更しません。文字色は濃いグレー・黒・濃紺・深緑のみ選択でき、白・透明は受け付けません。実測とは区分とファイル名も分けます。添付の説明にあった計画表示を省く指定は採用していません。

単票・全件出力、A4中央とレシート実寸（本文53.34×約57.57mm、模擬出力は枠外余白を含め約65.70mm高）、実寸100%の配置を維持しています。直接印刷はWindows専用で、対応しない用紙や印字領域の不足は停止します。クラウドでは印刷用寸法の計算と描画経路のみ検証し、Windowsダイアログ・プリンタードライバー・実印刷は未検証です。

同梱素材は添付セットの空欄背景、数字アトラス、座標定義のみです。原本PDF、実取引を含む出力見本、Excel、添付セット由来のbatは含めません。新規の安全なソース起動BATは、同じZIPのsourceに同梱します。クラウドで原本PDFとの再照合はしていません。Windows画面の起動も未検証です。
