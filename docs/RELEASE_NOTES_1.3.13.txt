1.3.13 未署名Windows確認用プレリリース

1.3.12-preview.1 の実コミットを基準に、AKTIOの計量入力・訂正履歴・運搬計画を独立モジュールとして追加。
帳票別のアプリ内自動保存先、東名vistaテーマ、既存データの保護を維持。
計画由来の単票・全件PDF/PNG・印刷には、明瞭な「計画 / PLAN」を必ず表示し実測と分離。
空車11180kg、3枚の指定時刻・SN、回数、10kg刻み重量上限、休憩・間隔・SN重複確認、固定seed、A4中央・実寸、保存再開を維持。

東名の基本書体を原本採取記録付き46字フォントに拡張。角文・殿・普通・配合計画書NOと数字・ハイフンに適用。
元の13字の輪郭・字幅は保持。旧13字の基本設定は一度だけ移行し、標準・独自書体・数字限定の明示設定と保存値は保持。
未収録字は選択した標準書体へ明示的に切り替える。フォントはアプリ内で使用しOSにインストールしない。
チェックは読みやすい推定レ点。原本採取字形とは区別して記録。原本PDFの再照合済みとは扱わない。

AKTIOに対応した診断と、画面を生成しないEXE用診断を追加。
同梱素材・定義・ハッシュ・ZIP内容を検査し、合成データで保存再開・計画表示・各帳票のPDF生成を検証。
Windowsビルドと診断の実行結果・使用フォント・スキップ件数は配布のpreview-validation.jsonを参照。
未検証: Windows 10/11の実デスクトップGUI、実プリンター・用紙寸法、原本PDFとの画素重ね合わせ。

署名付きGR Release Hub更新パッケージとは別の未署名確認用ZIP。
原本PDF、取引データ、ユーザー設定・DB、秘密情報は公開物に含めない。
PR #2のマージ、main変更、latest昇格、既存タグ・リリースの置換は行わない。
