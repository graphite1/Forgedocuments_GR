# Forgedocuments GR

Windowsで使う複数帳票の入力・管理・PDF出力アプリです。現在は「エーシー帳票」の運搬明細書画面を搭載しています。今後の帳票は専用画面として本体へ組み込み、アプリ更新で追加します。

## 起動

[GR Release Hub](https://gr-release-hub.rinntyu2000.chatgpt.site) からWindows ZIPを取得し、すべて展開して「Forgedocuments GR.exe」を開いてください。Pythonの事前導入・bat操作は不要です。帳票選択画面からエーシー帳票を開き、データ保存先を指定します。入力・保存・PDF出力はオフラインで利用できます。

## 主な機能

- エーシー帳票：入力、保存、訂正履歴、任意の累計計算、CSV取込・書出
- 選択記録・全件のPDF／PNG出力、プレビュー、Windows原寸印刷
- 青文字のドット印字と通常の太字を切替
- 共通プレビュー：右ドラッグで移動、Ctrl＋ホイールでカーソル位置を基準に拡大・縮小
- 全体表示・100％表示・複数ページの前後移動
- GRHubからの署名付き更新、保存前確認、バックアップ、更新版の起動確認と失敗時の復帰

会社名・住所・連絡先は公開設定に含めません。会社別のtemplate.jsonはエーシー帳票の「帳票設定」から取り込んでください。既存の記録と設定は元の保存先のまま引き継げます。

## 様式の追加と更新

[帳票追加・保存・更新の仕様](docs/PLATFORM.md) を参照してください。項目と計算は帳票ごとに分離します。既存のエーシー項目を別帳票へ固定しません。新しい原本を渡すだけで自動対応する機能は現在ありません。

## 開発

Python 3.14でrequirements-build.txtを導入し、verify.pyとverify_platform.pyを実行します。tools/build_windows.pyでWindows exeとGRHub用の署名付きZIPを作成できます。署名秘密鍵はWindows資格情報ストアに保存し、公開ソースや配布ZIPには含めません。

ソースから起動する開発用途ではstart_auto.bat／start.batも残しています。配布版はexeを使用してください。旧版に関するdocs内の起動説明より、このREADMEとPLATFORM.mdを優先します。

## 確認範囲

Windows環境で既存機能10件と共通機能7件の自動テスト、exeの起動診断・PDF描画・プレビューを確認しています。実機プリンターでの印刷、Python未導入の別PC、ARM端末は未確認です。外周枠117.3×153.0mmはスキャンからの暫定換算値で、設定から変更できます。
