# Forgedocuments GR

Windows用の「GR 運搬明細書」アプリです。帳票の入力、保存、訂正履歴、累計計算、PDF・PNG出力を行います。運搬明細書の項目・罫線を持つ設定例を同梱しています。会社名・住所・連絡先は含みません。

## 起動

1. リポジトリをZIPで取得し、すべて展開します。
2. `start_auto.bat` をダブルクリックします。
3. 初回は必要な部品を設定し、伝票データの保存先を選択します。

対応するPythonがなければ、Python公式サイトから3.14.3のWindows 64bitインストーラーを取得し、署名を確認して現在のユーザーへ導入します。初回はインターネット接続が必要です。Pythonが既にある場合は専用の `.venv` を作成します。管理者による導入制限があるPCでは自動設定が完了しない場合があります。

Pythonを手動で設定済みの場合は `start.bat` も使用できます。Tkinterを含むPython 3.11〜3.14、Windows 10/11 64bitを対象とします。

## 機能

- 原本から抽出した項目を入力し、SQLiteに保存
- No.・車両番号の先頭ゼロを保持
- 訂正理由と変更前後を記録、保管・復帰
- 明示実行時のみ選択した記録の累計を計算
- 選択行／全件のPDF・PNG出力とプレビュー、Windows原寸印刷
- A4中央・実寸と、帳票枠に合わせたページサイズ
- 青文字のドット印字／通常の太字の切替
- CSVの列名照合による取込・書出、バックアップ

## 帳票設定

固定文字、罫線、入力項目、配置、単位、印字条件は `template.json` で管理します。画面の「帳票設定」で設定を保存し、履歴を残します。別帳票の項目追加・削除には画面と帳票固有処理の改修も必要です。

初期の外周枠は117.3×153.0mmです。A4横スキャンからの暫定換算値で、紙原本の実測値ではありません。寸法は設定で変更できます。

原本の記入例・手書き署名・丸印は新規記録へコピーしません。数量単位の初期値は空欄で、kg等への換算は行いません。ドット印字は今回の原本に近づけた描画であり、元の印刷機の厳密な再現ではありません。

## 検証

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe verify.py
```

`check.bat` からも実行できます。保存・再読込・訂正履歴・累計・CSV・複数ページ・長文・受領印画像・Tkinter・印字設定の旧版移行を確認する10件の統合テストを含みます。テストは一時フォルダのみを使用します。

確認済み：Windows / Python 3.14.3での統合テスト10件、PDFの描画比較、PowerShell構文、既存Pythonの検出。

未確認：Python未導入PCでの自動導入から起動までの完走、実機プリンターでの印刷、複数PCによる同時編集。これらは実運用前の確認が必要です。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `app.py` | 入力・一覧・帳票設定の画面 |
| `core.py` | 保存、履歴、検証、PDF・PNG・CSV |
| `printing.py` | Windows原寸印刷 |
| `template.json` | 今回の帳票の項目と描画設定 |
| `start_auto.bat` | Python導入を含む起動 |
| `bootstrap.py` | 専用仮想環境と依存部品の設定 |
| `verify.py` | 統合テスト |
| `docs/` | 操作説明、変更内容、確認範囲 |

このリポジトリには提供された原本PDF、実際の伝票データ、署名画像、実行環境、データベースを含めません。GR Release Hubへの登録は別途行う作業で、このリポジトリの作成だけでは登録されません。

## 会社別の帳票設定

公開リポジトリの設定例では、社名・住所・連絡先の固定文字を空欄にしています。配布済みZIPに含まれる会社別 `template.json` を使う場合は、ローカルの「帳票設定 → 設定JSONを取込 → 設定を適用・保存」で読み込んでください。会社別設定や原本をこの公開リポジトリへ追加しないでください。
